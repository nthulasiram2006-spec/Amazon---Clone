# 🛒 Amazon Clone

A front-end clone of the Amazon homepage built using **HTML5** and **CSS3**. This project recreates the core layout and visual design of Amazon's landing page, including the navigation bar, hero section, product grid, and footer.

---

## 📸 Preview

The project replicates the following sections of the Amazon homepage:

- 🧭 **Navigation Bar** – Logo, delivery address, search bar, sign-in, returns & orders, and cart
- 📋 **Secondary Panel** – Menu, deals, customer service, registry, gift cards, and sell links
- 🖼️ **Hero Section** – Promotional banner with a "Click Here To Go To Amazon.in" message
- 🛍️ **Shop Section** – Product category cards (Health, Cosmetics, Furniture, Appliances, Mobiles, Laptops, Automobiles, Pharmacy)
- 🦶 **Footer** – Back to top, "Get to Know Us" links, logo panel, and copyright info

---

## 🎨 Customization

You can easily customize:

- 🎨 **Colors** – Modify background colors in `css/style.css` (e.g., `#000000`, `#222f3d`, `#374758`)
- 🖼️ **Images** – Replace the image files inside `assets/images/` with your own (keep the same filenames or update paths in HTML/CSS)
- 📦 **Product Cards** – Add or remove `.Box` divs in the `.Shop-Section`
- 🖼️ **Hero Banner** – Change `AMAZON SAMPLE.jpg` to your own promotional image
